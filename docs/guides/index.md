# Guides

!!! warning "Section under development"
    This section is currently being built. Content will be added progressively. Check back soon!

This section provides practical guides and quick-start resources for **umfoam** — an OpenFOAM-based solver for urban microclimate simulations. The goal is to lower the barrier to entry for researchers and practitioners who want to run urban CFD simulations.

---

## Planned Content

### 🔧 umfoam Installation
Step-by-step installation guide for umfoam on Linux systems. Covers dependencies, compilation from source, and environment setup.

### 🚀 Quick-Start Cases
Ready-to-run tutorial cases with annotated setup files. Designed to get you from zero to a working simulation in under an hour.

### 🌬️ Boundary Conditions Reference
Reference guide for the boundary conditions used in urban microclimate simulations: inlet profiles, wall functions, atmospheric boundary layer setup, and tree canopy conditions.

### 🧊 Meshing Helpers
Tips and scripts for generating urban meshes using cfMesh and snappyHexMesh. Includes guidance on geometry preparation, refinement levels, and quality checks.

### 📊 Post-Processing Tips
Workflows for extracting and visualising results: mean flow fields, turbulence statistics, thermal comfort indices (PET, UTCI), and time-series analysis.
